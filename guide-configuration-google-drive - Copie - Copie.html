GUIDE DE CONFIGURATION — GOOGLE DRIVE

فوج الوحدة — الحامية الكشفية (Scout El Wihda)

Version 2.0 • 2026
Objectif : Connecter votre Google Drive au site en 2 minutes pour que toutes les photos de la Galerie et des Annonces soient sauvegardées sur votre propre Drive, 100% gratuitement, sans limite de taille et sans frais d'hébergement.
1
Ouvrir Google Apps Script
فتح منصة سكريبت جوجل
  1. Dans votre navigateur, ouvrez le lien : https://script.google.com/home
  2. Vérifiez en haut à droite que vous êtes connecté avec le compte Google (Gmail) souhaité pour la troupe.
  3. Cliquez sur le bouton bleu « Nouveau projet » (New project) en haut à gauche.
2
Coller le Code de Liaison (Bridge)
لصق كود الربط البرمجي
  1. Dans l'éditeur de code, sélectionnez tout le texte par défaut (contenant function myFunction()) et effacez-le.
  2. Ouvrez le fichier google-drive-script.gs fourni avec votre site (ou cliquez sur le bouton « كود الربط وطريقة الإعداد » dans les paramètres admin puis « نسخ الكود »).
  3. Collez ce code dans la page vide.
  4. Enregistrez en appuyant sur Ctrl + S (ou cliquez sur l'icône de disquette).
3
Déployer en « Application Web » (Web App)
نشر المشروع كتطبيق ويب
  1. En haut à droite, cliquez sur le bouton bleu Déployer (Deploy) ➔ Nouveau déploiement (New deployment).
  2. À côté de « Sélectionner le type », cliquez sur la roue dentée ⚙️ et choisissez Application Web (Web app).
  3. Configurez les 3 paramètres exactement comme suit :
Paramètre Valeur à choisir Rôle
Description Scout Drive Bridge Nom indicatif du script
Exécuter en tant que (Execute as) Moi (votre-email@gmail.com) Le script utilise votre quota Google Drive
Qui a accès (Who has access) Tout le monde (Anyone) Indispensable pour que le site puisse envoyer la photo
  1. Cliquez ensuite sur le bouton bleu Déployer (Deploy) en bas de la fenêtre.

4
Accorder l'Autorisation Google (Écran de Sécurité)
منح الصلاحيات وتخطي شاشة الأمان

Une fenêtre Google s'ouvre pour valider l'accès à votre espace Google Drive :

  1. Cliquez sur « Autoriser l'accès » (Authorize access) et choisissez votre compte Google.
⚠️ Écran d'avertissement normal de Google :
Google affichera un message disant : « Google n'a pas validé cette application » (Google hasn't verified this app). C'est 100% normal car c'est votre propre script privé personnel.
  • Cliquez sur le lien en bas : Paramètres avancés (Advanced).
  • Puis cliquez tout en bas sur : Accéder à Projet sans titre (non sécurisé) (Go to Untitled project (unsafe)).
  • Cliquez enfin sur Autoriser (Allow).
5
Copier l'URL Web App et la Coller sur le Site
نسخ رابط تطبيق الويب ولصقه بالموقع
  1. Google vous affiche alors votre URL de l'application Web.
    Elle se termine par /exec (ex : https://script.google.com/macros/s/AKfycb.../exec).
  2. Cliquez sur le bouton « Copier » (Copy).
  3. Ouvrez votre site web (https://s4a.solution4all.dz/) et connectez-vous en Admin.
  4. Rendez-vous dans الإعدادات (Paramètres) ➔ إعدادات التخزين السحابي (Google Drive).
  5. Collez le lien dans la 1ère case :
    رابط تطبيق Google Apps Script (Web App URL — ينتهي بـ /exec)
  6. Cliquez sur le bouton violet : « اختبار الاتصال وتجهيز المجلدات ».
✔ Succès immédiat ! Le badge passe au vert : « جاهز للرفع المباشر إلى Google Drive ».
Le script crée automatiquement dans votre Google Drive le dossier « Scout_ElWihda_Media » avec deux sous-dossiers : « gallery » et « announcements ».
?
Dépannage Rapide (FAQ)
حل المشاكل الشائعة
  • Erreur CORS ou 403 : Vous avez omis « Qui a accès = Tout le monde (Anyone) » à l'étape 3. Cliquez sur Déployer ➔ Gérer les déploiements ➔ Modifier ➔ Anyone ➔ Déployer.
  • Le lien finit par /edit : Vous avez copié l'adresse de votre barre de navigation. L'adresse doit impérativement provenir de la fenêtre Déployer et se terminer par /exec.
  • Confidentialité : Le script ne touche qu'au dossier Scout_ElWihda_Media. Tous vos autres fichiers et photos personnels sur Google Drive restent strictement invisibles et privés.
